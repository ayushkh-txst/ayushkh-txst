### 🪝 [Snag](https://github.com/ayushkh-txst/snag)
**Stress-testing for LLM agents · in progress**

Paste in a system prompt and tool definitions, and Snag finds what breaks them. It pulls out the rules the prompt sets, attacks each one through every input the agent takes, and suggests fixes. The full interface is built. The scanning engine is next.

## 🧭 How I build

| | |
|---|---|
| 🔒 **Security first** | Sanitize input, check auth on every route, keep secrets and personal data off the client |
| 🔁 **Small PRs, real review** | Feature branches, reviewed pull requests, commit history you can read |
| 📐 **Design before code** | Architecture docs, ERDs, and API specs while the codebase is still small |
| 🗺️ **Show the system** | Every serious project gets an architecture diagram ([example](https://github.com/ayushkh-txst/jalrakshak-hackrice16/blob/main/docs/diagrams/g-one-architecture.svg)) |
